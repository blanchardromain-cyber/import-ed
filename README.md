# Import ED

Page personnelle de saisie EcoleDirecte (cahier de texte), servie par GitHub Pages.

- Aucune donnée ni aucun secret dans ce dépôt : la page appelle l'API du Worker
  `ecoledirecte-mcp` avec une clé saisie une fois dans ⚙ (stockée dans le navigateur).
- Toute écriture dans EcoleDirecte passe par une simulation puis une confirmation.
